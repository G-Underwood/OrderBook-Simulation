# market-maker-sim

A simplified market-making bot that quotes prices on a simulated order book, manages inventory risk, and tracks PnL over a simulated trading session.

## Aims

1. Build a working order book that can accept and match buy/sell orders.
2. Build a market-making bot that quotes bid/ask prices and adjusts based on inventory.
3. Run the bot through a simulated sequence of price movements.
4. Track and visualise PnL and inventory over time.

## Objectives

Initial Objectives for simplified version:

1. "Order" class
2. "OrderBook" class
3. Market-making bot
4. Simulation loop
5. Output
